个人主页，通过 GitHub Pages 发布。

## 关于

- **cyberjuglans / 赛博核桃** —— 多行业策划者。
- 追求效率与严谨，痴迷方法论，脑中装着无数新奇想法。
- 借 GitHub 分享想法，只要能给他人带来一丁点启发，便已足够。

## 内容

- `index.html` —— 单页个人主页（内联样式，无需构建，直接打开即可预览）。

## 本地预览

直接用浏览器打开 `index.html` 即可；或启动一个本地静态服务器：

```bash
python -m http.server 8000
# 然后访问 http://localhost:8000
```

## 发布（GitHub Pages）

仓库根目录的 `index.html` 即为站点入口。在仓库
**Settings → Pages** 中选择 `main` 分支、`/(root)` 目录并保存即可启用。
