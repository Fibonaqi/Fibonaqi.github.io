# 斐波那契 · Fibonaqi

个人主页，通过 GitHub Pages 发布。

## 关于

- **斐波那契 / Fibonaqi** —— 喜爱斐波那契数列，兼具艺术美感与严密逻辑的多行业策划者。
- 拥有独立审美，偏爱严谨风格；思想不设限，钻研方法论，怀揣无数奇思。
- 以 GitHub 为载体分享想法，只要能给他人带来一丁点启发，便已足够。

## 内容

- `index.html` —— 单页个人主页（内联样式 + 黄金螺旋 SVG，无需构建，直接打开即可预览）。

## 本地预览

直接用浏览器打开 `index.html`；或启动本地静态服务器：

```bash
python -m http.server 8000
# 访问 http://localhost:8000
```

## 发布（GitHub Pages）

仓库根目录的 `index.html` 即为站点入口。在仓库
**Settings → Pages** 中选择 `main` 分支、`/(root)` 目录并保存即可启用。
